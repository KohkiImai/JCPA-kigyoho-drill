# 企業法 穴埋めドリル

公認会計士試験 短答式「企業法」の過去問を、一問一答の2択穴埋め問題に作り直した学習用Webアプリです。
スマホのブラウザで開けば、インストールやログインなしで使えます。

## 収録内容

- 令和4年〜令和8年の第Ⅰ回・第Ⅱ回（10回分）の短答式「企業法」
- 各回20問×4肢＝**800問**
- 分野：商法総則・商行為／設立／株式／機関／計算／持分会社／社債／組織再編／金融商品取引法

## 問題の形式

本試験は「正しい肢の組合せを選ぶ」形式ですが、このドリルでは**1つの肢を1問**にしています。

- 各肢を正しい内容の文に直し、論点となる語句を空欄にしています。
- 選択肢は「正解」と「本試験のひっかけ」の2つです。
- 本試験で誤りだった肢は、誤りの部分を正しく直したものを正解、本試験の誤った記述をもう一方の選択肢にしています。

例：

> 支配人が商人の許可なく競業取引をしたときは、それによって得た利益の額は、商人に生じた損害の額と〔推定される／みなされる〕。

## 機能

### ドリル

- 試験回・分野で出題範囲を絞り込み
- ランダム出題／過去問の順
- 「前回まちがえた問題」「未回答の問題」だけを出題
- 回答後に解説と「あわせて確認」（関連論点・他の会社類型との比較・紛らわしい数字など）を表示
- 本試験でのその肢の正誤（原肢 正／誤）を表示
- キー操作：`1`・`2` で選択、`Enter` で次へ

### 問題一覧

- 試験回・問題番号・解答状況・キーワードで検索
- 肢ごとに解説を開ける
- 「この問を解く」「この肢を解く」でその問題だけを出題
- URLの末尾に `#list` を付けると、一覧の画面から開く

### 学習記録

- 累計正答率、要復習の数、肢ごとの解答状況をブラウザ（localStorage）に保存
- 記録はブラウザごと・端末ごとに別々です。サーバーには送信しません。

## ファイル構成

```
.
├── README.md
└── index.html   # アプリ本体（HTML・CSS・JS・問題データを1ファイルに収録）
```

外部ライブラリは使っていません。フォントだけ Google Fonts から読み込みます。読み込めない環境では端末のフォントで表示されます。


## 出典と注意事項

- **問題：** 公認会計士・監査審査会が公表している各回の短答式試験問題（企業法）をもとにしています。問題文は原文そのままではなく、学習用に要約・再構成しています。
- **正誤：** 令和4〜7年は同審査会公表の正解、令和8年は予備校（CPA会計学院）の解答解説を参照しています。予備校の解説文は転載していません。
- **解説：** 条文・判例をもとに独自に作成したものです。
- **法改正：** 出題後の法改正で結論が変わった肢（四半期報告書の廃止など）は、現行法に合わせた問題に置き換え、その旨を解説に記載しています。

解説の条文番号や内容には誤りが含まれている可能性があります。学習の際は必ず最新の条文で確認してください。
このドリルは個人の学習用に作成したもので、公認会計士・監査審査会や予備校とは関係ありません。
