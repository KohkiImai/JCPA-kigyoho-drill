# 企業法 穴埋めドリル

公認会計士試験 短答式「企業法」の過去問を、一問一答の2択穴埋め問題に作り直した学習用Webアプリです。
ブラウザだけで動き、インストールやログインは要りません。スマホでも使えます。

アプリはこのリポジトリの GitHub Pages で公開しています。ページ右上の **About** 欄のリンクから開いてください。

## 収録内容

- 令和4年〜令和8年の第Ⅰ回・第Ⅱ回（計10回）の短答式「企業法」
- 各回20問×4肢、**計800問**
- 分野：商法総則・商行為／設立／株式／機関／計算／持分会社／社債／組織再編／金融商品取引法

## 問題の形式

本試験は「正しい肢の組合せを選ぶ」形式です。このドリルでは、**1つの肢を1問**として出題します。

- 各肢を正しい内容の文に直し、論点となる語句を空欄にしています。
- 選択肢は「正解」と「本試験のひっかけ」の2つです。
- 本試験で誤りだった肢は、正しく直した語句が正解に、本試験の誤った記述がもう一方の選択肢になっています。

例：

> 支配人が商人の許可なく競業取引をしたときは、それによって得た利益の額は、商人に生じた損害の額と〔推定される／みなされる〕。

## 主な機能

### ドリル

- 試験回・分野で出題範囲を絞り込めます。
- ランダム出題と過去問の順を選べます。
- 「前回まちがえた問題」や「未回答の問題」だけを出題できます。
- 回答すると、解説と「あわせて確認」が表示されます。「あわせて確認」では、関連論点、他の会社類型との比較、紛らわしい数字などを補足しています。
- 本試験でその肢が正しかったか誤りだったか（原肢 正／誤）も表示します。
- キーボードでは `1`・`2` で選択、`Enter` で次の問題へ進みます。

### 問題一覧

- 試験回・問題番号・解答状況・キーワードで問題を探せます。キーワードは「特別決議」「423条」のような語句や条文番号でも検索できます。
- 肢ごとに解説を開いて確認できます。
- 「この問を解く」「この肢を解く」で、特定の問題だけをその場で解けます。
- URLの末尾に `#list` を付けると、問題一覧の画面から開きます。

### 学習記録

- 累計正答率、要復習の問題数、肢ごとの解答状況を記録します。
- 記録は使っているブラウザの中（localStorage）にだけ保存されます。サーバーには送信しません。端末やブラウザが変わると記録は引き継がれません。

## 手元で使う場合

`index.html` をダウンロードして、ブラウザで開けばそのまま使えます。
外部ライブラリは使っていません。フォントだけ Google Fonts から読み込み、オフラインでは端末のフォントで表示します。


## 出典と注意事項

- **問題：** 公認会計士・監査審査会が公表している各回の短答式試験問題（企業法）をもとにしています。問題文は原文そのままではなく、学習用に要約・再構成しています。
- **正誤：** 令和4〜7年は公認会計士・監査審査会が公表した正解、令和8年は予備校（CPA会計学院）の解答解説を参照しています。予備校の解説文は転載していません。
- **解説：** 条文と判例をもとに独自に作成しています。
- **法改正：** 出題後の法改正で結論が変わった肢（四半期報告書の廃止など）は、現行法に合わせた問題に置き換え、その旨を解説に記載しています。

解説の内容や条文番号に誤りが含まれている可能性があります。学習の際は、最新の条文で確認してください。
このドリルは個人が学習用に作成したもので、公認会計士・監査審査会や各予備校とは関係ありません。
